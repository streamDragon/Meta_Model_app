## Source of truth
- Website code is tracked in this GitHub repository. `main` remains the baseline until a change is reviewed.

## Rules
One application, one canonical Git repository, one manuscript plan. No destructive cleanup of historical source documents. Historical duplicates are catalogued, not silently erased. A Drive document or a lesson recording may be the only original of a passage.
